# Fonts for the reader

Two typefaces a book can be read in (the reader's Aa menu), Latin and Latin Extended only, as Google Fonts serves
them (fetched 2026-11). Both are under the SIL Open Font License 1.1 (the OFL files here).

- **Literata** (variable weight, with italics), designed for reading on screens.
- **Atkinson Hyperlegible** (regular and bold, with italics), made by the Braille Institute for easy reading.

`faces.css` lists them for the reader; the server serves this folder at `/fonts/`.
